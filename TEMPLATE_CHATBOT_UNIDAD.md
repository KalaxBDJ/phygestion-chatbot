# GUÍA PARA CREAR O ACTUALIZAR FLUJOS DE CHATBOT POR UNIDAD RESIDENCIAL

Documento de apoyo para administradores delegados y equipos administrativos de Propiedad Horizontal.

---

## Introducción

El objetivo de esta guía es recopilar de forma clara y organizada toda la información necesaria para crear o actualizar los flujos del chatbot de cada unidad residencial.

La información suministrada será utilizada directamente para configurar el chatbot, por lo que es importante que el documento sea diligenciado cuidadosamente y con información completa.

---

# 1. Instrucciones Generales

1. Complete este documento con la información exacta que desea que visualicen los residentes.
2. La información será utilizada directamente para configurar el chatbot.
3. No se realizarán interpretaciones ni redacción adicional sobre el contenido enviado.
4. Todos los enlaces deben ser públicos y funcionar sin iniciar sesión.
5. Si una respuesta requiere correo electrónico, incluya la dirección completa.
6. Utilice mensajes claros, concretos y fáciles de entender.
7. Revise cuidadosamente ortografía, enlaces y datos antes de enviar el documento.
